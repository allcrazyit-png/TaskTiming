# UI 重設計規格：40 歲以上中年女性作業員

**日期：** 2026-06-13  
**目標受眾：** 40 歲以上中年女性工廠作業員  
**範疇：** Home.jsx、Input.jsx（Confirm / BattleReport 不動）

---

## 背景與目標

使用者每天固定做同幾種產品、使用個人手機、徒手操作。目前 UI 的主要問題：
1. 登入入口隱藏在右上角小下拉選單，不易察覺
2. 預設字型偏小，不適合 40+ 視力
3. 首頁需要篩選（車型 → 品番）才能開始作業，步驟多、認知負擔高
4. 常用產品雖有星號功能，但顯示不夠突出

---

## Home 頁面重設計

### 未登入狀態（首次使用 / 登出後）

- 顯示全版畫面，標題「請選擇您的名字」（大字）
- 員工名字以列表顯示，每個名字為一個獨立大按鈕
  - 最小高度：64px
  - 字型大小：18px 粗體
  - 滿版寬度，清楚的邊框與間距
- 按下後彈出密碼輸入 Modal（現有設計保留，僅放大輸入框）

### 已登入狀態（有常用產品）

**上方問候區**（保留現有）：
- 姓名問候語，字型放大
- 日期 / 天氣資訊保留

**常用產品區（主要內容）：**
- 標題「我的常用產品」，左側紅心圖示
- 每個產品以**大型橫列卡片**顯示：
  - 左側產品圖片：80×80px 正方形，圓角
  - 右側文字：
    - 品名：18px 粗體，最多兩行
    - 車型：14px 灰色
  - 整排可點擊（不只按鈕），輕觸整列即進入作業
  - 右側「▶ 開始作業」按鈕，最小高度 64px，顏色依類別區分（保留現有色碼）
- 卡片間距加大（gap-4 → gap-5）

**無常用產品時：**
- 顯示引導訊息：「點擊產品卡片上的 ♡ 可加入常用」
- 直接展開篩選區

**底部「找其他產品」按鈕：**
- 灰色圓角按鈕，展開/收起篩選區
- 篩選器（車型 → 品番下拉選單）預設**收起**，點「找其他產品」才展開
- 篩選器內的產品清單顯示改為緊湊列表（無圖片）

### 整體字型預設

- `Home.jsx` 中 `useState` 初始值從 `'normal'` 改為 `'large'`：
  `const [fontSize, setFontSize] = useState(() => localStorage.getItem('appFontSize') || 'large');`
- 已有 localStorage 值的舊用戶不受影響（繼續沿用他們設定的值）
- 使用者仍可在設定中切換回普通大小

---

## Input 頁面改動

### 時間輸入區

- 維持手動輸入，不加「現在填入」按鈕
- **日期選擇器**：放大顯示，字型 16px，高度 48px，視覺上更明確（事後補填時日期很重要）
- 開始時間 / 結束時間輸入框：高度從目前 `py-2` 提高至固定 56px，字型維持 `text-xl`

### 良品計數

- `＋` 按鈕從 50×50px 放大至 **64×64px**
- `−` 按鈕同步放大至 64×64px
- `+10` / `+50` 快速按鈕高度提高至 64px（目前 `huge-btn` 的 min-height: 56px → 64px）

### 送出按鈕（Footer）

- 「完成，下一步」按鈕高度從 `h-14`（56px）提高至 `h-[68px]`
- 字型從 `text-xl` 提高至 `text-2xl`
- 「今天做完了」按鈕高度從 `h-12` 提高至 `h-14`

## 實作優先順序

1. `index.css`：`html:not(.text-large)` 預設改為 large（或直接修改初始化邏輯）
2. `Home.jsx`：未登入 → 全版名字列表
3. `Home.jsx`：已登入 → 常用產品大卡片，篩選器預設收起
4. `Input.jsx`：時間框放大、計數按鈕放大、送出按鈕放大
