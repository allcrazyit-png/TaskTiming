# 最新資訊與組裝區值日生設計

## 目標

讓組裝區作業員在 App 內快速確認本週男女值日生，同時保留既有今日組裝戰報。輪值順序對全員透明，但不妨礙日常只確認本週負責人的操作。

## 範圍

- 將底部導覽的「戰報」改為「最新資訊」。
- 既有戰報頁改為最新資訊頁；路由可維持 `/battle`，避免影響既有導覽與連結。
- 頁面最上方新增本週值日生卡片。
- 卡片可展開查看男女完整輪值順序。
- 原有今日組裝戰報保留在值日生區塊下方。

不包含：打掃完成勾選、管理者簽核、值日紀錄寫入後端，或線上編輯名單。

## 輪值資料與規則

名單直接定義於前端程式，順序如下：

| 組別 | 輪值順序 |
| --- | --- |
| 女生 | 林祐香、何淑如、陳玉薇、楊淑婷、黃舒嬪、陳麗如、何佩函、潘麗芳、杜氏美蓮 |
| 男生 | 毆吉、阿里、施聖浩、阿杜、楊子賢 |

- 基準週：2026/8/17（一）至 2026/8/21（五）。
- 基準週值日生：女生何佩函、男生楊子賢。
- 每週一切換到名單中的下一位；週數以基準週的週一為起點計算。
- 名單末位後循環至第一位。
- 例：2026/8/24 那週為女生潘麗芳、男生毆吉。

## 畫面與互動

在「最新資訊」頁最上方顯示大型值日生卡片：

```
本週組裝區值日生                         8/17（一）～8/21（五）

女生  何佩函              男生  楊子賢
下週  潘麗芳                        毆吉

[ 查看完整輪值順序 ]
```

- 女生與男生各以易辨識色塊和大字姓名呈現；資訊不依賴顏色本身，仍有文字組別標籤。
- 「查看完整輪值順序」為至少 64px 高的觸控按鈕，開啟頁內區塊或底部彈窗。
- 完整順序以女生、男生兩個區塊分開列出；本週人員標示「本週」，已輪過人員以較淡樣式呈現，後續人員按輪序顯示。
- 值日生區塊下方接既有的今日組裝戰報；所有既有資料取得、載入與錯誤顯示行為維持不變。

## 架構與資料流

BattleReport 元件新增純前端輪值設定與日期計算函式：

1. 取本機日期，找出當週週一。
2. 計算與 2026/8/17 的相差週數。
3. 對女生與男生各別以名單長度取餘數，得到本週索引。
4. 以索引產生本週、下週與完整名單顯示資料。

不呼叫 GAS、不讀寫 Google Sheet、不使用 localStorage；因此載入值日資訊不受網路延遲影響，也不會新增資料一致性風險。若日後頻繁換人，再改為由管理者維護的 Sheet 資料來源。

## 錯誤處理與測試

- 輪值資料為程式內常數，正常情況不會有載入錯誤。
- 日期計算需要涵蓋基準週、下一週、名單循環、基準週之前的週次。
- 驗證最新資訊頁仍可載入原戰報資料，且桌機／手機上按鈕與展開名單可正常操作。
- 執行既有 lint 與 production build；不在本次範圍內部署。
