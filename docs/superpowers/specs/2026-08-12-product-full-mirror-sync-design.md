# 產品全量鏡像同步設計

## 目的

讓 Supabase `task_timing_products` 成為 Google Sheet「產品總表」的完整鏡像，而非只新增或更新既有資料。

## 同步規則

1. 讀取「產品總表」所有列。
2. 品番空白的整列空白資料略過。
3. 品番重複時，以最後一列為準。
4. 將 Sheet 目前所有有效產品以品番為鍵新增或更新至 Supabase。
5. 讀取 Supabase 目前所有品番。
6. 刪除 Supabase 有、但目前 Sheet 品番清單沒有的產品。

同步完成後，Supabase 的產品品番集合必須與 Sheet 的有效品番集合完全相同。

## 使用者可見行為

- 同步結果顯示新增或更新的產品數量，以及刪除的舊產品數量。
- 網站仍只顯示類別不是「射出」的產品；「射出」資料仍保留在 Supabase 鏡像中。

## 安全與失敗處理

- 只有成功讀取並驗證 Sheet 至少有一筆有效產品後，才開始寫入或刪除 Supabase 資料。
- 新增／更新任一批失敗時，停止同步，不執行刪除。
- 刪除失敗時顯示錯誤，避免誤稱同步完成。
- Supabase service role key 仍只存在 Apps Script Script Properties，不寫入程式或前端。

## 驗收條件

1. Sheet 有的品番會新增或更新到 Supabase。
2. Sheet 已刪除的品番會從 Supabase 刪除。
3. 空白列不會產生 Supabase 資料。
4. 讀取或新增／更新失敗時，不會執行刪除。
5. 同步完成訊息同時顯示同步與刪除數量。
