# 組裝產品限定同步設計

## 目的

讓 Supabase `task_timing_products` 只保存網站組裝流程需要的非「射出」產品，不再保存射出產品。

## 同步規則

1. 讀取 Google Sheet「產品總表」所有列。
2. 品番空白的整列空白資料略過。
3. 類別等於「射出」的產品不納入 Supabase 同步集合。
4. 非射出產品若品番重複，以最後一列為準。
5. 將目前所有有效、非射出、唯一品番新增或更新到 Supabase。
6. 刪除 Supabase 內不在該同步集合的產品；包含 Sheet 已刪除的品番與既有射出產品。

同步完成後，Supabase 的產品集合必須與 Sheet 中所有有效、非射出的唯一品番集合完全相同。

## 同步訊息

完成訊息需顯示：

- 讀取的產品資料列數。
- 非射出同步筆數。
- 略過的射出筆數。
- 略過的重複品番筆數。
- 刪除的 Supabase 舊產品筆數。

## 安全與失敗處理

- 只有成功讀取並確認至少有一筆有效非射出產品後，才會寫入或刪除 Supabase。
- 新增或更新失敗時，停止同步，不執行刪除。
- 刪除失敗時顯示錯誤，不得顯示同步完成。
- service role key 仍只放在 Apps Script Script Properties。
