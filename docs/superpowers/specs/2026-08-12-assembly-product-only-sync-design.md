# 組裝產品限定同步設計

## 目的

讓 Supabase `task_timing_products` 只保存網站需要的非「射出」工序資料，並保留同品番的組裝、包裝、檢查等不同工序。

## 同步規則

1. 讀取 Google Sheet「產品總表」所有列。
2. 品番空白的整列空白資料略過。
3. 類別等於「射出」的產品不納入 Supabase 同步集合。
4. 同步唯一鍵是「品番＋類別」，不是單一品番。
5. 相同「品番＋類別」重複時，以最後一列為準。
6. 同品番但不同類別（例如組裝、包裝、檢查）必須各自保留、各自帶有自己的 CT 時間。
7. 將目前所有有效、非射出、唯一「品番＋類別」新增或更新到 Supabase。
8. 刪除 Supabase 內不在該同步集合的資料；包含 Sheet 已刪除的工序與既有射出產品。

同步完成後，Supabase 的產品集合必須與 Sheet 中所有有效、非射出的唯一「品番＋類別」集合完全相同。

## 資料表遷移

- 現有以 `part_number` 為主鍵的資料表必須改為以 `(part_number, category)` 作為複合主鍵或等效唯一鍵。
- 遷移後，舊有非射出資料仍保留；下一次完整同步會用 Sheet 最新資料覆蓋。
- 前端既有的我的最愛已使用「品番＋類別」，不需要改變其資料格式。

## 同步訊息

完成訊息需顯示：

- 讀取的產品資料列數。
- 非射出同步筆數（唯一「品番＋類別」數）。
- 略過的射出筆數。
- 略過的重複「品番＋類別」筆數。
- 刪除的 Supabase 舊產品筆數。

## 安全與失敗處理

- 只有成功讀取並確認至少有一筆有效非射出「品番＋類別」後，才會寫入或刪除 Supabase。
- 新增或更新失敗時，停止同步，不執行刪除。
- 刪除失敗時顯示錯誤，不得顯示同步完成。
- service role key 仍只放在 Apps Script Script Properties。
