# 飲水機旁看板螢幕：迷你電腦設定說明

這份說明給負責安裝螢幕的人。照著做，迷你電腦開機後會自動以全螢幕播放今日看板，不需要任何人登入。

## 你需要

- 一台迷你電腦（Windows），用 HDMI 接到螢幕，並連上公司網路（有線或 Wi-Fi 都可以）
- Google Chrome 瀏覽器
- 管理人員給你的**看板網址**，長得像這樣：

  `https://allcrazyit-png.github.io/TaskTiming/#/tv?key=<密鑰>`

  `<密鑰>` 是一長串英文和數字。這個網址等同看板的鑰匙，請不要貼在公開的地方。

## 1. 先試開一次

用 Chrome 開啟看板網址。

- 看到黑底白字的看板，就代表網址正確。
- 如果出現紅字「看板網址的密鑰不正確，請洽管理人員」，代表網址打錯或密鑰已經換掉，請向管理人員拿新的網址。
- 如果一直顯示「連線中…」，請檢查網路。

## 2. 設定開機自動全螢幕播放

1. 在桌面按右鍵 →「新增」→「捷徑」。
2. 「輸入項目的位置」貼上下面這一行，把 `<看板網址>` 換成真正的網址，**保留前後的雙引號**：

   ```
   "C:\Program Files\Google\Chrome\Application\chrome.exe" --kiosk "<看板網址>" --noerrdialogs --disable-session-crashed-bubble --disable-infobars
   ```

   如果 Chrome 裝在別的位置，請改成實際的 `chrome.exe` 路徑。
3. 捷徑名稱取「看板」，按「完成」。
4. 按鍵盤 `Win + R`，輸入 `shell:startup` 按 Enter，會開啟「啟動」資料夾。
5. 把剛剛的「看板」捷徑**複製**到這個資料夾。之後每次開機都會自動打開看板。
6. 雙擊捷徑測試：畫面應該變成全螢幕看板，看不到網址列和視窗邊框。

離開全螢幕看板：按 `Alt + F4`。

## 3. 不讓螢幕關掉、不讓電腦睡著

1. Windows「設定」→「系統」→「電源與睡眠」（或「電源與電池」）。
2. 「關閉螢幕」和「睡眠」都設成**永不**。
3. 如果電腦有 BIOS 設定「AC 斷電後恢復時自動開機」（常見名稱：*Restore on AC Power Loss*、*AC Power Recovery*），請設為**開啟 / Power On**。這樣停電後復電，電腦會自己開機、自己回到看板。

## 4. 收尾

- 設定完成後，把鍵盤和滑鼠收起來，迷你電腦放在不容易被碰到的地方。
- 看板每 1 分鐘自動更新一次；右上角綠點旁會顯示「即時 · 更新於 HH:MM」。
- 如果右上角變成紅色「連線中斷 · HH:MM 的資料」，代表暫時連不上網路，畫面會保留最後一次的資料，網路恢復後一分鐘內會自己接上。
- 每天凌晨 4 點，看板會自己重新整理一次，這是正常的。

## 用量

看板只有在網頁開著時才會讀取資料，每分鐘一次，一個月大約 130 MB，遠低於 Supabase 免費方案的額度。迷你電腦關機時完全不會用到。

## 換密鑰（網址外流或想更換時）

由管理人員操作：

1. 在自己的 Mac 或電腦終端機產生新密鑰和它的雜湊值：

   ```bash
   KEY=$(openssl rand -hex 32); echo "新密鑰：$KEY"; printf %s "$KEY" | shasum -a 256 | cut -d' ' -f1
   ```

   第一行是新密鑰（記下來），第二行是雜湊值。

2. 到 Supabase 後台 →「SQL Editor」，執行（把 `<雜湊值>` 換掉）：

   ```sql
   delete from public.task_timing_board_keys;
   insert into public.task_timing_board_keys (key_hash, label) values ('<雜湊值>', '飲水機旁螢幕');
   ```

   執行後，舊網址會立刻顯示「密鑰不正確」。

3. 把新網址 `https://allcrazyit-png.github.io/TaskTiming/#/tv?key=<新密鑰>` 更新到迷你電腦「啟動」資料夾裡的捷徑（右鍵 →「內容」→「目標」），然後重新開機。
